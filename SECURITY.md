# Segurança e privacidade

- Este repositório contém apenas **código e exemplos**, sem chaves de API, seed phrases ou banco real.
- O episódio de credencial exposta em screenshot foi removido dos materiais de portfólio; a credencial foi orientada a ser regenerada.
- A API paga do X está desativada no código de referência.
- Não commit `*.sqlite`, `*.sqlite-wal`, `*.sqlite-shm`, `.env` ou logs com credenciais.
- Não há mecanismo de envio de transações para blockchain. Nunca informe seed phrase a scripts ou a terceiros.
- Heurísticas de risco não constituem auditoria. Não use a simulação como autorização para operar dinheiro real.
- Não execute arquivos `.bat` de terceiros sem inspecionar.
